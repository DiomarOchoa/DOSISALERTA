# docs/presentation/

Carpeta reservada para el material de sustentación (guion, diapositivas
y demo), que se prepara en la Fase 9, cuando el sistema ya exista y se
pueda demostrar con datos reales.

No se crea material de presentación en la Fase 0: presentar capturas o
flujos de un sistema que aún no existe sería engañoso para la evaluación.
